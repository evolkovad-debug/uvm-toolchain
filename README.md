# Ассемблер и интерпретатор УВМ

## 1. Общее описание

Учебная виртуальная машина (УВМ): стековая машина с отдельной памятью
команд и памятью данных. Проект содержит ассемблер (JSON в машинный
код) и интерпретатор. Реализованы этапы 1–2: перевод программы из JSON во внутреннее
представление (поля A, B, C) и в машинный код (байты).

## 2. Язык ассемблера и настройки

Программа — JSON-список команд. Каждая команда — объект с полем `op`
и операндами:

| op           | Операнды                 | Что делает                      |
|--------------|--------------------------|---------------------------------|
| `load_const` | `value`                  | положить `value` на стек        |
| `read`       | `address`                | положить на стек память[address]|
| `write`      | `offset`                 | снять значение и адрес со стека |
| `shr`        | `address`, `offset`      | логический сдвиг вправо         |

Все операнды — целые числа от 0 до максимума, который помещается в
поле команды (`value` — 26 бит, `address` — 18 бит, `offset` у `write`
и `shr` — 15 бит). Лишние и пропущенные поля считаются ошибкой.

Пример:

    [
      {"op": "load_const", "value": 1009},
      {"op": "shr", "address": 208, "offset": 386}
    ]

Параметры ассемблера:

- `ИСХОДНИК` — путь к JSON-файлу с программой.
- `ВЫХОД` — путь к двоичному файлу-результату.
- `--test` — режим тестирования: вывести байты команд на экран.

При ошибке печатается «Ошибка: ...», код возврата 1.

Формат машинного кода: команда — целое число, собранное из полей
(поле A занимает биты 0–5, остальные поля — свои биты по спецификации),
записанное в байты по порядку от младшего к старшему. Размеры команд:
`load_const` — 4 байта, `read` и `write` — 3, `shr` — 5.
Результат записывается в двоичный файл без разделителей. После
ассемблирования выводится число команд.

## 3. Запуск и тесты

    ./run.sh asm examples/spec_tests.json out.bin --test
    python3 -m unittest discover -s tests -t .

## 4. Примеры

    ./run.sh asm examples/spec_tests.json out.bin --test

Вывод:

    Ассемблировано команд: 4
    0x40, 0xFC, 0x00, 0x00
    0x24, 0x35, 0x00
    0xE6, 0xA9, 0x00
    0x3D, 0x34, 0x00, 0x82, 0x01

Содержимое файла можно посмотреть командой `hexdump -C out.bin`.
